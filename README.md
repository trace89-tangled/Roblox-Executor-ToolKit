## FAQ

### Is this safe to use?

XCutors is a launcher for third-party tools. The included executors themselves carry inherent risks; use them at your own discretion and review their individual documentation.

### How do I update the executors?

XCutors will automatically check for updates when launched. You can also manually trigger an update check from the Settings tab.

### Which versions of Windows are supported?

XCutors is designed for Windows 10 and Windows 11 (64-bit). Compatibility with older versions is not guaranteed.

### Why won't a script execute?

Common reasons include an outdated executor, a Roblox security update, or the script containing unsupported functions. Check the executor's log for details.

### Can I add my own scripts to the hub?

Yes. You can add custom scripts by placing them in the 'Scripts' folder or using the 'Add Script' option within the application.

### Does this work with Roblox Studio?

No. XCutors and the included executors are designed solely for the live Roblox client, not the development environment.

### Is there a key system?

Some individual executors may require a key. The xcutorsLoader aims to streamline this process where possible, but key requirements are set by each executor's developers.

### Where can I report bugs or suggest features?

Please open an issue on the GitHub Issues page with a clear description, including your system specs and steps to reproduce the problem.
